# Smart Classroom and Timetable Scheduler



📌 Description



The Smart Classroom and Timetable Scheduler is a full-stack web application designed to automate and manage classroom activities in educational institutions. It provides a centralized platform for Admins, Teachers, and Students to handle academic operations efficiently, reducing manual work and improving communication.



🚀 Features



🔐 Authentication \& User Management



\* Secure login and registration system

\* Role-based access control (Admin, Teacher, Student)

\* Restricted access based on user roles 



📅 Timetable Scheduler



\* Create and manage class timetables

\* Assign subjects, teachers, classrooms, and time slots

\* Avoid scheduling conflicts

\* Dynamic timetable updates (substitution \& rescheduling) 



🧾 Attendance Management



\* Teachers can mark student attendance

\* Students can view attendance records

\* Accurate and structured data storage 



📚 Notes \& Study Materials



\* Teachers upload study materials

\* Students can view and download notes anytime

\* Organized subject-wise content 



📢 Announcement System



\* Admins/Teachers can post announcements

\* Students receive updates on dashboard

\* Displays title, description, and date 



📝 Leave Management



\* Students and staff can apply for leave

\* Admin/Teacher can approve or reject requests

\* Track leave status (pending/approved/rejected) 



❓ Query Handling System



\* Students can raise academic queries

\* Teachers can respond to queries

\* Improves communication between users 



🧠 AI Assistance (Partial / Future)



\* Designed for AI-based support

\* Can assist students with queries (future enhancement) 



📊 Dashboard \& Output System



\* Role-based dashboards (Admin/Teacher/Student)

\* Displays timetable, attendance, announcements

\* Real-time updates and structured data display

▶️ How to Run



Backend:



1\. Open backend in IntelliJ

2\. Run:



&#x20;  ```bash

&#x20;  mvn clean install -X

&#x20;  mvn spring-boot:run -X

&#x20;  ```

3\. Runs at: http://localhost:8080



Frontend:



1\. Open frontend in VS Code

2\. Run:



&#x20;  ```bash

&#x20;  npm install

&#x20;  npm start

&#x20;  ```

3\. Runs at: http://localhost:3000
